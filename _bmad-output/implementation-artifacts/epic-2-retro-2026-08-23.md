## Part 1 — Epic Review

### 1.1 Delivery Summary

- **Stories delivered:** 2-1 (spawn ceiling) · 2-2 (fixed 40/40 weights) · 2-3 (tiered pot) · 2-4 (halving-decay curve) · 2-5 (configurable spawnConfig) · 2-6 (engine integration: merge-once + effective-move + pendingSpawn snapshot)
- **Test suite:** 186 → **280 pass / 0 fail** (~50% growth); `tsc --noEmit` clean on both configs.
- **Signature mechanic shipped:** tiered 20% pot opening by board ceiling, fixed 1/2 at 40/40, configurable halving-decay curve — landed byte-for-byte compatible with the original spawn distribution at every step.
- **Backward-compat pins (`game.test.ts` boundary assertions) stayed green UNCHANGED across all six stories**, while the spawn resolver was rewritten three times (two-stage → weighted two-stage → combined single-roll).

### 1.2 What Went Well

- **The immutable `GameState` + `pendingSpawn` snapshot landed exactly as the Epic 1 retro demanded.** ADR-06 satisfied; Epic 7's Ambiguous Preview now consumes an existing structure with zero refactoring. Architecture paying dividends early.
- **Byte-for-byte backward compatibility as a discipline.** Every story pinned existing behavior before changing it; scope guards ("do NOT do the next story's work") were written into each spec and respected — the uniform intra-pot pick (2.3) was a documented placeholder surgically replaced by 2.4.
- **Fixed RNG draw-budget contract** (effective=3 / noop=0 / newGame=20 / resolver=1) closed the variable-draw-count deferred item and locked determinism.
- **Deferred-work ledger gained real closures** — three 2.3 items CLOSED-by-story 2.6 with citations; the ledger is becoming a living instrument, not a graveyard.
- **ATDD red-green flow used consistently** (RED scaffolds verified before GREEN implementation in 2-4/2-5/2-6).
- **Adversarial review caught structural bugs, not noise:** `potForTier(1e8)` allocation bomb (MAX_POT_TIER cap), `weightedPicker([])` returning `-1`, the noop path aliasing `pendingSpawn` by reference (silent ADR-06 violation), `pickIndex(0)` → `-1`.

### 1.3 What Didn't Go Well (systems, not individuals)

- **Out-of-scope changeset content resolved by retroactive amendment (story 2-2).** Dev-only deps (`tsx`, `react-test-renderer`) plus six new test suites rode along outside the File List, literally contradicting the Dev Notes' "no external dependencies" guard. Resolution was to emend the Dev Notes after the fact. It worked, but normalizes "amend later" instead of "amend before."
- **Doc/count drift RECURRED after being flagged.** Epic 1 retro committed to CI-emitted test counts; story 2-3's review still found "claims 230 tests, actual 236," and 2-2's automation summary contradicted its own test-review report (194 vs 224). Count/doc drift appeared in **4 of 6 stories** (2-1 uncommitted patches, 2-2 contradictory docs, 2-3 inaccurate record, 2-6 ledger stats drift). Not bad luck — a system gap.
- **Statistical gates were fragile until late.** Story 2-6's third-pass review discovered the AC7 conditional-frequency gate **never executed** (seed produced fewer pot samples than the floor) — a dead green gate — plus a ~13% flake knife-edge tolerance. Fixed in the same pass via a shared 5σ `sigmaBound` helper, but only on the third adversarial pass.
- **Review intensity concentrated on one story:** 2-6 required three full passes. Each pass found real items; the dev pass keeps shipping hardening/coverage gaps that review catches.
- **Carried-over open debt:** engine contract reconciliation (`ok | rejected` vs `moved: boolean`) — flagged in Epic 1 retro as "before Epic 3" — remains unresolved; T5.2 on-device p99 gate still open; purity scan still hand-maintained (mitigated per-module with inline purity tests in ceiling/pot/weights, but the escape class persists).

### 1.4 Breakthrough Moments (precedent for later work)

1. Immutable snapshot `{ board, pendingSpawn }` with state-placement master rule — the load-bearing structure for Epic 3 undo and Epic 7 preview.
2. Combined single-roll resolver (`pickCombined`/`resolveSpawn`) consulting `POT_WEIGHT` directly — closes the config-coupling question.
3. Fixed draw-budget contract documented on `Rng`.
4. `sigmaBound` 5σ pattern for statistical gates — reusable convention.
5. Inline source-keying purity tests per new pure module (workaround that works).
6. Deferred-work CLOSED-by-story markers convention.

### 1.5 Technical Debt Incurred

**High**
- **Engine contract reconciliation still open** — engine returns `{ board, score, moved, trace, pendingSpawn }`, never adopts the architecture's `ok | rejected` union. Epic 3's `undo(): ok | rejected` atomic contract (ADR-02) must be resolved at the orchestrator level (snapshot GameState + app-owned score) without breaking the engine. *Close before story 3-5.*
- **T5.2 on-device p99 < 16.7 ms gate — still OPEN after two epics.** Close during early Epic 3 (menu UI stories leave gameplay untouched).

**Medium**
- Purity scan hand-maintained (`PURE_MODULES` / `PURITY_FILES` lists); inline per-module purity tests are a working mitigation but every new pure file can still silently escape the global scan.
- Statistical gates: σ-budget undocumented as a project convention (partially addressed by `sigmaBound`).
- Malformed-input hardening class (malformed rng / malformed GameState degrade instead of throw) — deliberately deferred, trust-the-input posture within valid API domain.

**Low**
- Ad-hoc `{ board: result.board, pendingSpawn: result.pendingSpawn }` reconstruction duplicated across 5+ call sites (no shared `stateFromResult` helper).
- Circular-oracle risk in formula-recomputed cumulative band pins (hand-computed tier pins partially compensate).
- `spyRng` serves silent 0.5 after exhaustion; `gameState()` magic default `{ value: 1, displayRoll: 0 }` drives migrated assertions.

### 1.6 Testing & Quality Insights

- Strong deterministic coverage growth: 186 → 280 tests, all seeded, no flakes after the sigmaBound fix.
- Dead-gate lesson: a frequency gate whose seed starves below its floor passes green forever — floors must be verified against the actual seed stream (now done; floor 200→50 so tier ≥ 1 executes).
- The default-tsconfig vs tsconfig.test.json split catches different type errors (2-5 lesson, applied in 2-6: run both gates).

### 1.7 Velocity / Complexity Signals

- 2-1 through 2-5: clean incremental ladder, each story extending the previous without refactors — the scope-guard chain worked.
- **2-6 was the epic's cost center** (intentional signature/API change: `move(state, dir, rng)`, `newGame(rng) -> GameState`, mechanical port of ~20 consumer files, five pinned-test rewrites) and needed three review passes.
- Pattern confirms Epic 1's: API-shape-change stories concentrate review churn; pure-additive stories flow.
