# Story 6.1: Overlay de game over com stats imediatos

Status: done

<!-- Note: Validation is optional. Run validate-create-story for quality check before dev-story. -->

## Story

As a player,
I want my run's full stats the moment it ends,
So that I can understand what happened and what to chase next.

## Acceptance Criteria

1. **Given** a match that reaches game over (grid full and no adjacent mergeable pair — `isGameOver(board) === true`), **When** the game-over state fires, **Then** the overlay shows immediately: `score`, `best score`, `max tile`, `number of merges`, and `longest streak` (FR-25, UX-DR-12, EXPERIENCE.md:73).
2. **And** the stats appear without any forced wait — no timer, no artificial delay gates the overlay; the last move stays visible behind the stats (FR-27, D-010).
3. **And** the stats are lane-scoped where relevant (`best` = active lane's live `match.best` seeded from `persistedBest` via `initialScore`/`isNewRecord`; `best` never derived from global). (P3, FR14).
4. **And** game over is a state, not an error — the engine emits no throw; `isGameOver` is called on the post-move board, and the overlay renders from app-owned `MatchScore` + `MatchStats` (architecture error handling, `move()` never throws, ADR-02/06).
