## Project Overview

**3-clone** is a mobile-first, dependency-free PWA clone of the puzzle game "Three!" (Threes-style sliding tiles). A pure, framework-free rules engine (`js/game.js`, UMD-exported) is consumed by a thin DOM/UI layer (`js/ui.js`); the app ships as a static PWA with a service worker for offline play, a web manifest for installability, and self-generated icons. 26 unit tests cover the rules engine via Node's built-in test runner.

## Quick Reference

- **Tech Stack:** Vanilla JS (ES5 + some ES6), HTML5, CSS3, `localStorage`, Service Worker, Web Manifest
- **Entry Point:** `index.html`
- **Architecture Pattern:** Layered client-only (rules engine → presentation)
- **Database:** None (no server, no API)
- **Deployment:** Static hosting; no build step, no Docker, no CI/CD

## Getting Started

### Prerequisites

- Node.js 18+ (tests + icon generation)
- Modern browser with service worker support (HTTPS or `localhost`)

### Setup

```bash
# No install step — zero dependencies, no package.json
```

### Run Locally

```bash
python3 -m http.server 8080
# or: npx serve
# then open http://localhost:8080
```

### Run Tests

```bash
node --test
```

### Hard Boundaries to Respect:

- Zero runtime dependencies, no build step.
- Game rules live **only** in `js/game.js`; the UI never duplicates them.
- Keep the UMD export so `node --test` keeps working.
- Spawn only after an effective move; one-cell movement; merge-once per swipe.
