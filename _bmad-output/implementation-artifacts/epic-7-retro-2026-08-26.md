- **ADR-06 snapshot paying off for second epic in a row.** 7-1 proved Epic 2 retro's #1 win: `PendingSpawn { value, displayRoll }` in `GameState` needed only test/guard coverage — engine forward contract from 2.6 (AC6: "pre-resolved pendingSpawn lives in snapshot from day one") fulfilled with zero refactors. Pattern confirmed load-bearing for Epic 3 undo as well.
- **Pure display-decision module reuse.** `src/game/preview.ts` (`previewFor`) mirrors `matchScore.ts` precedent — host-testable, no `rng`/`Math.random`, no engine roll imports, no RN deps. `PreviewCard.tsx` stayed dumb-presentational, Hud thin-view boundary (`ui.thinview.test.ts`) stayed green without modification across all stories (orchestrator computes `Preview`, view only renders).
- **Byte-for-byte engine invariant as discipline confirmed.** 4 stories, 4× `git diff --stat -- triade/src/engine` empty — enforced by CI purity guard and story scope guards ("do NOT rewrite engine", "do NOT rebuild card"). Review accepted the boundary split (Hud receives `Preview` not `PendingSpawn`) as architecture-aligned.
- **FR-43 hardening pattern worked.** 7-2 shipped a basic contiguous window (caps at 3), 7-3 surgically hardened it to ceiling-driven availability (`potForTier(tierForCeiling(ceilingDetector(board)))` once per render, after `if(!ready)` guard, both lanes identical) — no card rebuild, no engine change. Deferred gap from 7.2 ("content semantics owned by 7.3") CLOSED cleanly.
- **ATDD red-green kept rigor:** 7-3 failed 4 FR-43 pins RED before implementation; 7-4 swept FULL [1,2,3,6,12,24,48,96] × four display branches × pot-only availabilities plus 4-direction materializations — 17 tests proving invariant, plus 4 rewind invariants extending 7-1 suite.
- **Adversarial 3-layer review caught real structural issues, not style:** `Number.isFinite` guards on `displayRoll`/`value`, `displayOf` malformed-preview guard, `LANE_STACK_GAP` magic offset → named constant, `setGame` stable identity, `RANGE_1_2` frozen for memo, `availablePot` moved below ready guard.

- **`tsc -p tsconfig.test.json` waiver carried across 4 stories.** Waived in 7-1 with owner approval (pre-existing TS5101 abort + 3 masked RN stub errors), recorded and re-verified in 7-2/7-3/7-4 — no new errors, but the emergency fallback (default `npx tsc --noEmit`) remains the real CI gate. Ledger entry keeps growing without closure.
- **Two-lane fan-out vs single-lane scope guard tension needed a Decision.** 7-2 review opened `decision_needed`: spec says "single-lane first" yet Hud introduced `previews: { clean, accelerated }` with two stacked LanePreview boxes. Owner resolved "keep fan-out, per-lane differentiation lands in Epic 3" and traceability gate pre-accepted 7.2-AC3 as IMPLEMENTED — correct, but the discussion cost a cycle; CC 2026-08-23 seam should have been an explicit scope note in 7-2 from birth.
- **Doc/count drift recurred once.** 7-4 File List documented 14 tests while file had 17 (O-1 + right/down materializations) — patch fixed 2026-08-26. Less severe than Epic 2's 4-of-6 drift, but the class persists despite Epic 2 retro action item "ban counts or emit from CI".

### 1.4 Breakthrough Moments (precedent for later work)

1. **Snapshot preview as zero-state projection** — preview adds zero new state, is pure projection of `pendingSpawn` (`previewFor` reads it, never re-rolls). State-placement master rule reaffirmed.
2. **Availability passed from orchestrator, not derived in display** — `App.tsx: availablePot = potForTier(tierForCeiling(ceilingDetector(board)))` once per render → both lanes identical, no engine change. Pattern for Epic 3 lane memory (single computation, fan-out).
3. **`RANGE_1_2 = Object.freeze([1,2])` stable identity** for React memo — micro-optimization that preserves memoization across calls; applied on hot path.
4. **Three independent FR-44 separation pins (value/position/timing)** — value: same board+pending but 0.2 vs 0.9 yields identical spawn cell/value; position: candidates derived only from `shiftLine.moved` opposite-edge, never from Preview; timing: `previewFor` has no `rng` param → 0 draws, pinned via `spyRng.calls.length`.
5. **Rewind-shape proof extending 7-1** — shallow-copy `{...pendingSpawn}` in `game.ts:88` + `GameState { board, pendingSpawn }` reconstruction replay proves snapshot carries preview; mutation of result never rewrites history; noop deep-equal + 0 draws.
6. **`sigmaBound`/helpers shared-utils convention** — `test-utils/helpers.ts` now canonical for `sigmaBound`, `runSeededSession`, `stripCommentsAndStrings`, `extractNamedImports`, `rngOf`/`spyRng`.
